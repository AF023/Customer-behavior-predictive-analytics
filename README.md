# 📊 Customer Behavior & Predictive Analytics Pipeline

## 📌 Overview
This project delivers an **Exploratory Data Analysis (EDA)** combined with a **Machine Learning predictive model** to analyze customer behavioral traits, income distributions, and purchasing propensity. 

Built using Python, Pandas, Seaborn, and Scikit-Learn, this project demonstrates core data science capabilities tailored for commercial optimization and marketing intelligence.

---

## 🏗️ Tech Stack & Methodology
- **Data Manipulation & Stats:** Python, Pandas, NumPy.
- **Data Visualization:** Seaborn, Matplotlib.
- **Predictive Modeling:** Scikit-Learn (Logistic Regression for interpretable classification).
- **Files in Repository:**
  - `customer_predictive_analysis.ipynb`: Full EDA, statistical correlations, and model training workflow.
  - `customer_behavior_data.csv`: Processed behavioral dataset.

---

## 📈 Key Exploratory Insights
- **Income vs. Spending Correlation:** High-income segments exhibit distinct clustering behaviors regarding discretionary spending scores.
- **Tenure Impact:** Customer loyalty duration correlates moderately with recurring product adoption.
- **Predictive Accuracy:** The logistic regression classifier achieved reliable baseline performance in segmenting high-value buyers based on behavioral attributes.

---

## 🎯 Business Applications
1. **Targeted Marketing Campaigns:** Isolate high-propensity customer groups to optimize advertising budgets.
2. **Churn Prevention & Retention:** Identify behavioral drop-off patterns early in the customer lifecycle.
3. **Dynamic Pricing & Upselling:** Tailor product recommendations according to historical income and spending indicators.

---

## 🚀 How to Run
Open `customer_predictive_analysis.ipynb` in Google Colab or any Jupyter notebook environment and execute all blocks sequentially.
